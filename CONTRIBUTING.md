# Contributing to InteractEmbed

Thank you for helping improve InteractEmbed. Please report defects and feature
requests in the [public issue tracker](https://github.com/InteractEmbed/moodle-block_interactembed/issues).

Contributions should:

- remain compatible with Moodle 4.5 through 5.2;
- follow Moodle coding, security, privacy and accessibility guidance;
- include automated tests for behavioural changes;
- keep user-facing strings in the Moodle language API;
- avoid adding grades, activity completion or learner analytics to this block;
- preserve the security boundary around remote iframes and HTML5 packages.

Run Moodle Plugin CI, PHPUnit and the browser recipe before proposing a change. By contributing, you agree that your work is distributed under GNU GPL v3 or later.
